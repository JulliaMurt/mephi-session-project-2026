# mephi-session-project-2026

## 1. Установка дистрибутива
- **1.1. Настройка сети:** Сетевой интерфейс настроен на получение IP-адреса по протоколу DHCP.
- **1.2. Настройка имени хоста:** Установлено имя хоста `mephi-2026.domain.local`.
- **1.3. Проверка связности:** Выполнен ping до `8.8.8.8`. Результат сохранен в `ping.out`.

## 2. Управление программным обеспечением
- **2.1. Обновление:** Выполнено обновление пакетов (`dnf update`).
- **2.2. Установка из репозиториев:** Установлены `nginx` и `libcap-ng-utils`.
- **2.3. Локальный RPM:** Пакет `tcpdump` скачан в `/tmp` с помощью `dnf download` и установлен локально с помощью `rpm -ivh`.
- *История транзакций:* `dnf.out`.

## 3. Управление файловыми системами
- **3.1. Создание ФС:** Второй диск `/dev/sdb` разбит на один раздел `/dev/sdb1`, отформатирован в `ext4` с меткой тома `MEPHI_WEB`.
- **3.2. Монтирование:** Создана точка монтирования `/mephi-web`. Настроено автоматическое монтирование в `/etc/fstab` с использованием `LABEL=MEPHI_WEB`. Выполнено ручное монтирование.
- *Доказательства:* файл `fstab`, а также `stat.out`.

## 4. Управление сервисами
- **4.1. Веб-сервер:** Сервис `nginx` запущен и добавлен в автозагрузку.
- **4.2. Журналирование:** Собраны логи nginx за текущую загрузку. Сохранены в `journalctl.out`.

## 5. Управление доступом
### 5.1. Дискреционное управление доступом (DAC)
- Создана директория `/data/mephi-2026`.
- Созданы разработчики: `user1` (UID 5501), `user2` (5502), `user3` (5503). Для них настроены общие права на чтение/запись с помощью ACL и SGID-бита на директории.
- Созданы кураторы `mentor` и `teacher` (группа `curators`, GID 4444). Для них настроены права только на чтение (`r-x`).
- Для остальных пользователей доступ закрыт (`---`).
- *Доказательства:* `stat.out`, `passwd`, `group`.

### 5.2. Привилегии (уменьшение количества set-UID-программ)
- С утилиты `tcpdump` удален бит set-UID.
- Утилите выданы привилегии `cap_net_raw,cap_net_admin+ep` с помощью `setcap`.
- Проверено, что пользователь `user1` может успешно запускать `tcpdump`.
- *Доказательства:* `getcap.out`.

### 5.3. Мандатное управление доступом (MAC)
- SELinux работает в режиме `Enforcing`.
- Настроен SELinux-контекст `httpd_sys_content_t` для нестандартной директории `/mephi-web` с помощью `semanage` и `restorecon`.
- *Доказательства:* `getenforce.out`.

## 6. Аутентификация
- **6.1. Ограничение входа:** Кураторы заблокированы для локального входа с помощью `usermod -L`.
- **6.2. Управление паролями:** 
  - Срок действия паролей установлен 90 дней (`chage -M 90`).
  - Минимальная длина пароля установлена 12 символов в `/etc/security/pwquality.conf`.
- *Доказательства:* `pwquality.conf`, `shadow` *(хэши удалены)*.
